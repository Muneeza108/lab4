# Software Construction – Lab Task 04

**UET Abbottabad Campus | 5th Semester Software Engineering**

## Objective

To understand Java mutability, immutability, collections, iterators, and unmodifiable collections.

## Lab Tasks

* **StringPerformance.java:** Compared `String` and `StringBuilder` performance.
* **CourseManager.java:** Demonstrated `ConcurrentModificationException` and safe removal using `Iterator`.
* **TreasureMap.java:** Used `HashMap` to store and calculate treasure values.
* **Zoo.java:** Used `Collections.unmodifiableList()` to prevent modification.

## Homework

* **StudentDirectory.java:** Used `Map` and an unmodifiable `Set` of student IDs.
* **Point.java:** Created an immutable class using `final` fields and no setters.

## Testing

JUnit tests were created to verify the implemented functionality.

## How to Run

Open the project in **Apache NetBeans**, right-click a Java file, and select **Run File**.
For tests, right-click the test file and select **Test File**.
